# Principles

Durable guidance for this template:

1. **Template stays domain-light** — sample code teaches pattern; product rules are opt-in.
2. **Flyway owns schema** — JPA never invents tables in running apps.
3. **Feature packages over technical layers** — vertical slices first.
4. **WWG close-out is part of the task** — code-only changes are incomplete when truth moved.
5. **Anti AI-slop** — code stays consistent and lean; see [`anti-ai-slop.md`](anti-ai-slop.md) (mandatory).
6. **Spring Boot best practices (speed & stability)** — see [`spring-boot-best-practices.md`](spring-boot-best-practices.md) (mandatory guardrails).
